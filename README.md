# Desarrollo de Videojuegos Metroidvania-2D
Juego estilo Metroidvania postapocalíptico, donde la protagonista "Elisa Myers", debe rescatara a su hermana "Samara Myers" que se encuentra perdida por Chernóbil. Para esto deberá enfrentar una variedad de enemigos afectados por la radiación y abrirse paso entre las salas del Reactor 4.
